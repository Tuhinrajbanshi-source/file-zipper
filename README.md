# file-zipper
A DSA-based file compression and decompression utility using Huffman Coding.
Compression
Original File
     ↓
Find character frequency
     ↓
Build Min Heap
     ↓
Create Huffman Tree
     ↓
Generate Huffman Codes
     ↓
Encode the file
     ↓
Compressed File


Decompression
Compressed File
     ↓
Read stored information
     ↓
Build Huffman Tree
     ↓
Decode the data
     ↓
Original File
